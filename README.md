# Hurricane Sandy flood model — showcase

Static site (GitHub Pages) showing a preliminary SFINCS compound-flood hindcast of Hurricane
Sandy (28–31 Oct 2012) on the New Jersey coast and Delaware Bay. Generated from the research
repo's `naccs-premier` run on the `v4_refreeze` domain; the build scripts live in that repo
under `logs/showcase_2026-10-19/`. Preliminary results, not peer-reviewed.
